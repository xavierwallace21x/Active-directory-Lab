# Active-directory-Lab
## Overview

I built a virtualized Windows Server and Active Directory environment
to gain hands-on experience with technologies commonly used by IT
Support and Help Desk professionals.

The lab was created using Oracle VirtualBox with Windows Server and
Windows 11 virtual machines.

## Technologies Used

- Windows Server
- Active Directory Domain Services (AD DS)
- Active Directory Users and Computers (ADUC)
- DNS
- TCP/IP
- Oracle VirtualBox
- Windows 11

## Lab Objectives

The purpose of this project was to develop practical experience with
Windows Server and Active Directory administration in a simulated
business environment.
## What I Configured

- Created Windows Server and Windows 11 virtual machines using VirtualBox
- Configured Windows Server networking for the lab environment
- Installed and configured Active Directory Domain Services
- Created the Lab.local Active Directory domain
- Used Active Directory Users and Computers to manage directory objects
- Created user accounts
- Created organizational containers for accounts and groups
- Created departmental security groups including Finance and HR
- Practiced basic Active Directory user and group administration

## Skills Demonstrated

- Windows Server administration
- Active Directory
- User account management
- Security group management
- DNS fundamentals
- TCP/IP configuration
- Virtualization
- Windows administration
- ## What I Learned

This project helped me understand how Active Directory is structured and
how IT administrators manage users and groups within a Windows domain
